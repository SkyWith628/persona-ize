# apps/web — React + TypeScript UI (5주차)

아직 비어 있다. 백엔드 `/docs`(Swagger)로 1~4주차 실험을 진행하고, UI는 5주차에 만든다.

예정 화면 (project-design §3): 상대 목록 / 페르소나 편집 / 대화 가져오기 / 작성 화면(상대 선택·초안·상황) / 추천 비교(바뀐 부분·경고·적용/취소) / 데이터 관리.

시작할 때: `npm create vite@latest . -- --template react-ts`. 백엔드 CORS는 `http://localhost:5173`을 허용한다.
