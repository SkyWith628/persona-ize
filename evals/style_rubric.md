# 스타일 루브릭 v0 (5점)

작성: 평가·품질 담당 (초안은 팀장, 2026-11-08). 블라인드 사람 평가와 LLM judge(G-Eval 형태)가 같은 표를 쓴다.
**사실 보존은 이 표로 평가하지 않는다** — 보존 실패는 점수와 무관하게 실패다.

평가자는 조건(A/B/C/D)을 모른다. 같은 원문의 결과들을 무작위 순서로 본다.

| 축 | 1 | 3 | 5 |
|---|---|---|---|
| 관계 적합성 | 상대·관계에 맞지 않음 (상사에게 반말, 친구에게 공문체) | 무난하지만 어색한 부분 있음 | 이 상대에게 바로 보낼 수 있음 |
| 설정 반영 | 격식·길이·이모지·호칭 설정을 무시 | 일부만 반영 | 설정을 모두 반영, 금지 표현 없음 |
| 나다움 (C/D만) | 사용자의 과거 말투와 동떨어짐 | 비슷하지만 어색 | 본인이 쓴 것 같음 |
| 자연스러움 | 번역투·문법 오류·과한 수식 | 읽히지만 매끄럽지 않음 | 자연스러운 한국어 |
| 수정 부담 | 거의 다시 써야 함 | 한두 곳 손봐야 함 | 그대로 적용 가능 |

## 쌍대 선호 (개인화 효과)
같은 원문의 A 결과와 C 결과를 나란히 보여주고 "어느 쪽을 보내겠는가"를 고른다. **본인 말투 적합성은 사용자 본인**이 평가하고, 제3자는 관계 적합성·자연스러움만 평가한다.

## 기록 양식 (`results/human_eval_*.csv`)
`case_id, condition(blind id), rater, relation_fit, settings_fit, selfness, naturalness, edit_burden, preferred_over, comment`
