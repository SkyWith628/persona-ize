# 평가 (담당: 평가·품질)

`eval_cases.csv` 열 설명 (1주차에 팀이 확정, 초안):

| 열 | 뜻 | 예 |
|---|---|---|
| case_id | 사례 번호 | E001 |
| relation | 받는 사람과의 관계 | 팀장 / 동기 / 교수 / 동생 |
| situation | 상황 한 줄 | 일정 늦어져서 양해 구하기 |
| original_text | 사용자가 쓴 초안 | 오늘 정리해서 내일 오전까지 보내드릴게요 |
| preserve_items | 바뀌면 안 되는 항목 (`;`로 구분) | 날짜=내일 오전;행동=보냄 |
| expected_notes | 좋은 첨삭의 조건, 나쁜 예 | 높임 유지, 시간 변경 금지 |
| needs_graph | 여러 대화에 흩어진 사건 연결이 필요한가 (Y/N) | Y |

`needs_graph=Y` 사례는 지식그래프 담당이 표시한다. D 채택 판정에 쓴다.
