# 그래프 스파이크 점검 보고 (Graphiti P0)

D 경로(지식그래프) 사전 검증. 판정 기준과 실행법은 [graphiti_p0/README.md](graphiti_p0/README.md), 판정은 `docs/decisions.md`에 기록한다.

공통 환경: Neo4j Aura Free(`5.27-aura`), 추출 LLM `claude-haiku-4-5`(graphiti 0.31.2), 임베딩 로컬 `intfloat/multilingual-e5-small` 384차원, 데이터 `data/synthetic/sample_conversations.json` 36개 에피소드(대화방 4, 인물 5). 실행 기록은 `graphiti_p0/runs/`(git 제외). 모두 2026-11-08 하루에 돌렸다.

## 4차에서 확인한 것

**효과 있음**
- 수신자 명시 → 엣지 0개 에피소드 5 → 0, 자기참조 엣지 2 → 0, 무타입 엔티티 1 → 0. 짧은 답("일단 알겠어요", "좋아 내가 날짜 잡을게")도 관계·관여 사실이 됐다.
- `hierarchy` 분리 → 김민수→박지현 target_higher, 박지현→김민수 target_lower, 김준호→김민수(형) target_higher, 이서연→김민수 equal → 발령 후 target_higher. 3차의 superior/subordinate 방향 혼동이 사라졌다(1건 예외: 10-14 "팀장으로서 칭찬" 발화에서 박지현→김민수 target_higher).
- 이서연 장면: 동기 반말(equal) 엣지가 발령 시각에 `invalid_at`, 이어서 존댓말·혼용·'민수님' 호칭 엣지가 생김. 설계한 bi-temporal 전개 그대로.

**효과 없음**
- **요일을 적어 줘도 날짜 산술은 틀린다**: 10-05(월) 기준 "다음 주 수요일" → 10-15(정답 10-14), "목요일" → 10-10(토요일), "이번 주말" → 10-07(수요일), 10-09(금) 기준 "다음 주 토요일" → 10-18·10-12(정답 10-17). haiku-4-5는 요일 산술을 안정적으로 못 한다. → 지시문으로 더 밀지 않고 **코드에서 상대 날짜를 미리 풀어 본문에 주석으로 붙이는 규칙 기반 해석기**(예: `다음 주 수요일(=2026-10-14)`)가 다음 수단.
- 말투 판정이 실행마다 흔들린다: c1:m07 "죄송합니다"가 3차는 존댓말, 4차는 반말. 김준호(동생)→김민수가 존댓말로 찍힌 엣지도 있다. 어미 규칙을 적어도 비결정성이 남는다 → 말투는 그래프 추출값을 참고로만 쓰고(설계 원칙: 페르소나 설정을 덮어쓰지 않음), 규칙 기반 어미 판정을 코드로 두는 쪽이 맞다.
- relation_type이 같은 쌍에서 흔들린다: 김민수↔김준호가 family/friend/acquaintance 혼재, 최유진이 friend/colleague/acquaintance 혼재. "이전 사실의 값을 유지"라는 지시로는 안 잡힌다 → 쌍별 relation_type은 추출값 다수결 또는 `evals/characters.csv`의 등록값으로 고정하는 후처리가 필요.
- "Relationship·Involved만" 규칙의 부작용: 사건 엔티티를 못 세운 발화("일정 조정에 동의", "밥 먹기로 약속")가 Relationship 엣지로 들어간다. 사실은 보존되지만 사건 중심 검색에서는 안 잡힌다.

## 비용

토큰·금액은 graphiti가 돌려주지 않아 **Anthropic Console 사용량 페이지에서 확인**한다. 오늘 haiku-4-5 호출은 수집 7회(5 + 36 + 1 스모크 + 36 × 4) = 186 에피소드분. 에피소드당 haiku 호출은 3~5회(노드 추출·엣지 추출·속성·중복 판정·요약). 시간은 지시문 길이와 무관하게 에피소드당 11~12초.

## 환경에서 걸린 것 (코드로 해결, 커밋됨)

- **Aura TLS 검증 실패** `self-signed certificate in certificate chain`: Aura 인증서가 SSL.com 루트인데 새 Windows PC의 루트 저장소에 그 루트가 없었다. `load_settings()`가 `SSL_CERT_FILE` 미설정 시 certifi 번들을 지정해 해결.
- **`temperature` TypeError**: anthropic SDK 2.6.0 `messages.create`에 `temperature`가 없는데 graphiti 0.31.2가 넘긴다. `GraphAnthropicClient`가 호출 직전에 떼어낸다.
- `ingest.py`가 스파이크 폴더의 `.env`만 보던 것을 상위 폴더(루트 `.env`)까지 찾도록 수정.
- `strict_edge_types`는 `add_episode_bulk`에만 있어 순차 수집에서는 못 쓴다. 지시문으로 대체.
- 시각은 UTC로 저장(graphiti 프롬프트 전제), `inspect_graph.py`가 KST로 표시.
- 소음: graphiti가 인덱스 생성을 두 번 병렬로 시도해 Aura가 `EquivalentSchemaRuleAlreadyExists`를 20여 줄 찍는다. `participant_role` Literal 위반('참석자')은 graphiti가 재시도로 처리.

## 판정 제안 (팀 결정은 `docs/decisions.md`)

- 병합(5/5)·bi-temporal 무효화(설계 장면 포함)·커스텀 속성(44/49)·날짜(24/25)·한국어 하이브리드 검색이 **기전으로 전부 동작**한다. 비용·시간(에피소드당 ~12초, haiku)은 문제 없다. **D 인프라 선택(Graphiti + Aura/로컬 Neo4j + haiku 추출)은 유지.**
- 지시문 보강은 3차에서 구조 품질을 크게 올렸고 4차에서 남은 구조 문제를 닫았다. 날짜·말투·관계 유형의 일관성은 **지시문이 아니라 코드(해석기·후처리·등록값)로 푼다.** 더 이상의 지시문 반복은 비용 대비 효과가 낮다.
- **D 채택 조건(needs_graph=Y에서 C 대비 개선)은 C가 생기는 2주차에 같은 질의로 판정**한다. 3·4차 수치(q01 0.40, q03 0.67)가 D 기준선이고, 비교 전에 같은 설정 2~3회 반복으로 분산을 잰다.
