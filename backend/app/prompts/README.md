# 프롬프트 폴더

비전공자가 문서처럼 수정하는 곳이다. 파일 하나 = 프롬프트 하나. 수정은 브랜치 → PR로 올린다.

| 파일 (예정) | 담당 | 용도 |
|---|---|---|
| `rewrite.md` | 사용자·시나리오 | 첨삭 지시문 (페르소나 설정을 어떻게 문장에 반영할지) |
| `verify.md` | 평가·품질 | 보존 항목·금지 표현·스타일 검증 지시문 |
| `extract_preserve.md` | 평가·품질 | 원문에서 날짜·수량·약속 등 보존 항목 추출 |

규칙: 변경할 때마다 파일 맨 위에 `버전`과 `변경 이유` 한 줄을 적는다.
