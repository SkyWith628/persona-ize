아이디 이메일 이름 가입 방법 상태 권한 가입일 마지막 로그인 오늘 첨삭 상대 수 관리

관리자 화면에 나오지 않는 것

  • 대화 원문과 첨삭 문장은 운영 콘솔 어디에도 표시하지 않습니다.
  • 피드백 사유 글도 보여 주지 않고, 입력했는지 여부만 봅니다.
  • 품질·피드백 표의 사용자는 가린 표시(u_ 뒤 6자)입니다.
  • 회원관리를 위해 아이디·이메일·표시 이름은 사용자 메뉴에 그대로 보입니다.

회원을 삭제하면 지워지는 것

  • 등록한 상대와 상대별 페르소나 설정
  • 가져온 대화방과 메시지, 문체 예시 묶음
  • 첨삭 이력과 피드백
  • 관계 그래프(사건 정리 결과)
  • 사용량 기록과 로그인 세션
  • 계정 자체(아이디·이메일·연결된 소셜 로그인)

삭제는 바로 실행되고 되돌릴 수 없습니다. 그래프 삭제가 실패해도 DB의 데이터는 지워지며, 그 경우 삭제 결과에 그래프 오류가 함께 표시됩니다.
