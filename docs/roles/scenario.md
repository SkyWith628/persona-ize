## 어떻게 하나

1. **대화 쓰기**: 시트에 `대화방 | 번호 | 날짜시간 | 말한 사람 | 내용` 다섯 열. 말한 사람은 이름을 써도 되고 `me`/`contact`도 된다. 날짜시간은 `2026-10-05 09:25` 형식. 한 방 5~10줄.
2. **흩어진 사건 만들기**: 한 사건을 두 방 이상에 나눠 쓴다. 예) 동기 방: "다음 주 금요일 회식 올 거지?" → 친구 방: "금요일 회식 때문에 못 가" → 동기 방(며칠 뒤): "회식 다음 주로 미뤄졌어". 이런 장면이 그래프(D)가 C보다 나은지 판정하는 근거다. 만들면 **그래프 담당에게 알려** 질의로 적게 한다.
3. **올리기**: GitHub Desktop → 새 브랜치 `scenario/…` → CSV 또는 JSON 커밋 → PR → 팀장 리뷰. CSV를 올렸으면 PR 설명에 "변환 요청"이라고 적는다(팀장이 `scripts/csv_to_synthetic.py`로 변환).
4. **화면으로 확인**: `make up` → `make dev` 뒤 http://localhost:8000 에서 상대를 만들고 과거 대화를 붙여 넣은 뒤 조건 C로 첨삭해 보면, 내가 쓴 대화가 "참고한 과거 표현"에 뜨는지 볼 수 있다. 실제 Claude 호출은 돈이 드니 `.env`는 `LLM_PROVIDER=fake`로 두고 흐름만, 실제 품질은 팀장과 함께.

## 반드시 지킬 것
- **실제 대화를 넣지 않는다.** 이름·날짜·장소를 바꿔도 실제 사건이면 안 된다. 이 데이터는 외부 서비스(Claude, Neo4j)로 간다.
- 등장인물은 `characters.csv`의 이름을 쓴다. 호칭("지현 팀장님", "팀장님")은 일부러 섞어도 좋다(그래프 병합 시험).
- CSV는 **UTF-8**. 엑셀은 "CSV UTF-8"로 저장.
