# 시연 대본 (2026-11-24 고쳐 씀 — demo 계정의 카카오톡 대화 551건 기준)

11/09 대본은 합성 대화 36건(박지현·이서연·김준호·최유진) 기준이었다. demo 계정을 11/19에 카카오톡 내보내기 4개로 바꿨으므로 장면을 새로 잡았다. 아래 결과는 모두 11/24에 이 PC에서 실제 모델(Opus 5.5, `rewrite-v3`, 규칙 `rules-2026-11-24.2`)로 돌려 본 것이다.

준비: Docker Desktop → `docker compose up -d --wait postgres neo4j` → 서버(`make dev`) → http://localhost:8000 에서 **demo** 계정으로 로그인(비밀번호는 팀장이 전달). `.env`는 `LLM_PROVIDER=anthropic`, `NEO4J_URI=bolt://localhost:7687`. 모바일 화면은 http://localhost:8000/m.
데이터: 상대 4명(김상무님 130건·이과장 200건·박영수 92건·Michael Brown 129건), 말투 설정 v1, 그래프 수집 완료(에피소드 551개). 다시 만들려면 `scripts/load_kakao_demo.py --config <설정> --user demo --yes --graph`(그래프 약 80분·19달러 — 시연 전에 다시 만들지 않는다).
**시연 전에 아무 첨삭 하나를 미리 돌려 워밍업한다**(서버 시작 직후 첫 C/D 요청은 10초쯤 걸린다).

## 시연 전 확인 — 경로가 깨지지 않았는지 (모델 호출 없음)
코드를 고친 뒤와 시연 전날에 돌린다. 아래 장면 0~5를 합성 대화(상사·동료·영어 상대·말투가 변한 지인, 카카오톡 PC .csv 꼴)로 끝까지 태우고, 깨지면 `[실패] 장면 2 · D 첨삭 — HTTP 500 code=…`처럼 어느 장면의 어느 단계인지 말한다.
- 개발 PC(Docker, 서버·DB 불필요, 1~2초): `make demo-check-docker` — make가 없으면 `docker compose --profile test run --rm test pytest -q -s -p no:cacheprovider tests/test_demo_flow.py`. CI의 pytest에도 들어 있다.
- 떠 있는 서버에(HTTP, Postgres까지 지나간다): 가짜 모델로 띄운 서버(`CLAUDE.md` 함정의 `pi-verify` 명령, 8101)에 `python3 scripts/demo_check.py --base-url http://web.localhost:8101`. 임시 계정을 만들고 끝에 지운다. **시연 서버(`LLM_PROVIDER=anthropic`)에는 돌리지 않는다** — 스크립트가 거부한다(첨삭 7회 + 메시지 80건의 그래프 수집 비용).
- 화면까지(선택, Playwright가 있는 환경에서만): `node scripts/demo_ui/demo_ui_check.cjs --base-url <가짜 모델 서버> --out <캡처 폴더>`.
- **이 검사가 못 보는 것**: 가짜 모델은 초안을 그대로 돌려준다. 문장이 다듬어지는지, 장면 1 C·2·3의 **주의 문구**, C와 D의 차이, 원문 유지, demo 계정의 실제 데이터·그래프(551건)는 보지 못한다. 그건 아래 대본을 실제 모델로 돌리는 리허설이 본다.

한 장면은 2~3분, 전체 10분 안. 조건 전환은 첨삭 폼의 "고급 · 실험 조건".

## 1. 상사에게 보고 — 사실 보존과 격식 (B → C)
- 상대 **김상무님**(상사). 말투 설정: 격식 5, 호칭 "상무님", 금지 "ㅋㅋ·ㅠ".
- 초안: `하늘식품 견적 단가는 VAT 별도 52,000원으로 고쳤어요. 요약본은 내일 오전 8시 반까지 드릴게요.` · 상황 `보고`
- 조건 **B**: "상무님, 하늘식품 견적 단가는 VAT 별도 52,000원으로 수정하였습니다. 요약본은 내일 오전 8시 반까지 드리겠습니다."(3회 모두 이 꼴, 3~4초). '지킨 항목'에 `내일`·`오전 8시 반`·`52,000원`·`약속 표현`이 뜬다.
- 조건 **C**: 문장은 비슷하고, 주의에 "이전에 상무님이 VAT 포함 57,200원으로 적으라고 하셨던 기록이 있습니다 … 확인해 주세요"가 떴다(1회 확인). 과거 대화에서 읽은 것을 본문에 넣지 않고 **경고로만** 쓴다는 점을 말한다.
- 말할 것: 보존 항목은 규칙으로 검증하고, 틀리면 재생성 1회, 그래도 틀리면 원문 유지. 금액의 쉼표·약속 어미는 표기가 달라도 같은 값으로 본다.

## 2. 거래처에 일정 변경 — 과거 약속과 엇갈림 (C → D)
- 상대 **이과장**(지인·거래처). 호칭 "이과장님".
- 초안: `2차 입고는 11월 14일은 어렵고 11월 21일까지는 가능합니다.` · 상황 `일정 조율`
- 조건 **C**: "이과장님, 2차 입고는 11월 14일은 어렵고 11월 21일까지는 가능합니다. …" + 주의 "11/07에 2차 생산 완료를 14일 오전으로 안내하신 적이 있습니다. 이번에 14일이 어렵다고 하시는 것과 엇갈려 보일 수 있으니 …".
- 조건 **D**: 주의에 "사실 맥락에 2차 11월 14일 입고 일정이 있습니다. 그 건을 말하는 거라면 …" — 그래프의 사실을 근거로 든다.
- **알아 둘 것**: 대화가 2025년 것이라 두 조건 모두 "오늘 기준으로 이미 지난 날짜입니다" 주의가 함께 뜬다. 숨기지 말고 "날짜를 오늘 기준으로 풀어서 견준다"는 설명 거리로 쓴다.
- 말할 것: 가능/불가가 뒤집히면 검증이 막는다(`어렵고`·`가능합니다`가 지킨 항목에 보인다).

## 3. 영어로 해외 거래처에 — 그래프 맥락 (C vs D)
- 상대 **Michael Brown**. 호칭 "Michael".
- 초안: `We can't sign the agreement on October 15. I'll send the revised draft by Friday.`
- 조건 **C**: 정중한 영어 문장으로 다듬고 주의 없음.
- 조건 **D**: 주의에 "Earlier notes show a plan to sign the agreement in person in Chicago on October 15 …" — 그래프의 "10월 15일 시카고에서 서명" 계획과 이었다(C 0/1, D 1/1).
- '지킨 항목': `October 15`·`Friday`·`can't(불가)`·`I'll send(약속)`. 영어의 날짜·부정·약속도 한국어와 같은 규칙으로 검증한다는 점을 말한다.
- 대안 초안(수량): `Hi Michael, we can't ship the 4,500 pcs by Oct 17. I'll send the revised schedule by Friday 3pm.` → `4,500`·`Oct 17`·`3pm`이 온전히 지켜진다.

## 4. 말투가 바뀐 상대 — 모델을 부르지 않는 제안
- 상대 화면에서 **박영수** → "과거 대화 기준 제안 보기".
- "박영수 님에게 쓰는 말투가 바뀐 것으로 보여요: 해요체(14건) → 합쇼체(최근 2건, 2025-10-18부터)", 계기(그래프) "장비 공동구매", 최근 말투가 섞여 있어 **값을 정해 주지 않고 사용자에게 묻는다**.
- "근거 메시지 보기"를 눌러 **바뀌기 전 해요체 마지막 3건과 바뀐 뒤 합쇼체 2건의 원문**을 카드 안에 펼친다 — 왜 이런 제안이 나왔는지를 내가 실제로 보낸 메시지로 보인다(11/27 추가, demo 계정 데이터로는 리허설에서 확인할 것).
- 말할 것: 제안은 규칙으로만 읽고(모델 호출 없음) 누르기 전에는 저장되지 않는다. 설정이 과거 말투보다 우선이다.
- 이어서 "맥락 그래프 보기"(모바일 화면 `/m`의 상대 화면)로 사람·사건·사실 93건을 보여 줄 수 있다.

## 보험
- **API 크레딧이 0이면 모든 Claude 호출이 400으로 실패한다**. 시연 전날 Console에서 잔액을 확인한다.
- **Docker Desktop이 꺼지면 서버가 선다.** Claude 세션의 셸에서 띄우면 세션과 함께 죽는다(`CLAUDE.md` 함정) — 시연 날은 시작 메뉴에서 직접 띄운다. 꺼졌으면 다시 띄우고 `docker compose up -d --wait postgres neo4j`.
- Opus 거절이나 검증 실패가 나오면 재생성 1회 뒤 원문 유지가 뜬다 → "장애 시 원문 유지가 원칙"이라고 말하고 다시 누른다.
- 주의 문구는 모델이 쓰므로 매번 같지 않다. 장면 1 C·장면 3 D의 주의는 1회씩만 확인했다 — 안 뜨면 "다시 만들기"를 한 번 누른다.
- 그래프 맥락이 안 붙으면(조건 D인데 C와 같음) `scripts/graph_names.py --user demo --dry-run`으로 상대 이름과 노드 이름이 맞는지 본다.
- 인터넷·API 장애 → `.env`의 `LLM_PROVIDER=fake`로 흐름만 보여 준다(원문 그대로 반환).
- 아이폰 앱은 유효한 인증서의 HTTPS 서버에만 붙는다. 로컬 서버로 시연하면 모바일은 브라우저의 `/m`으로 보여 준다.
