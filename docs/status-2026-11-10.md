**비용**: 11/09 새벽에 API 크레딧이 바닥나 그래프 수집이 멈췄다(충전 뒤 재개). 사례 120개 × 4조건 × 3회 = 1,440회 예산을 잡으려면 Console의 실제 금액 확인이 필요하다(팀장).
