## 0. 30초 소개
"상대와 상황에 맞게 **내 말투로** 다듬지만, 날짜·가능/불가·약속 같은 **사실은 절대 바꾸지 않는** 첨삭 도우미입니다. 자동 전송은 없고, 추천을 복사해 직접 보냅니다." 화면 상단 사용량(오늘 n/200회)을 가리키며 "사용량 한도도 걸려 있습니다".

## 1. 팀장에게 거절 — 사실 보존과 내 과거 표현 (C)
- 상대 **박지현**(상사) 선택. 페르소나 v1: 격식 5, 호칭 "지현 팀장님", 금지 "ㅋㅋ·ㅠ".
- 과거 대화 "박지현 팀장님과의 업무 대화"를 열어 10/05 일정 조율 장면을 보여 준다(내가 "죄송하지만 수요일로 조정 부탁드립니다"라고 썼던 것).
- 첨삭: 상황 `거절`, 조건 **B** → 원문 `이번 주 금요일은 어렵고 다음 주 수요일까지는 가능합니다.`
  - 기대: "지현 팀장님, …" 호칭이 붙고 금요일 불가·수요일 가능이 그대로. 11/08 실측에서 B는 "금요일**까지는**"으로 뜻을 바꿀 뻔했고 모델이 warnings에 자인했다 → **주의 블록**을 펼쳐 보여 준다.
- 같은 원문을 조건 **C**로 다시 → "참고한 과거 표현"에 10/05 메시지 id가 뜨고, 결과에 과거에 쓴 "죄송하지만"이 들어온다. "이게 내 말투를 가져오는 부분입니다."
- 말할 것: 보존 항목(가능/불가·날짜)은 규칙으로 검증하고, 틀리면 재생성 1회, 그래도 틀리면 원문 유지.

## 2. 동기에게 사과 — 관계가 바뀐 뒤 어조 (D)
- 상대 **이서연**(동기). 과거 대화에서 10/17 "파트장 발령" 이후 내가 존댓말·"서연 파트장님"으로 바뀐 장면을 보여 준다.
- 첨삭: 상황 `사과`, 조건 **D** → 원문 `어제는 제가 좀 예민했던 것 같아요. 미안합니다.`
  - 기대: 결과는 "정말 미안해요" 정도의 부드러운 존댓말. **주의**에 "최근 회사에서는 '서연 파트장님' 호칭을 써 오셨습니다. 필요하면 직접 붙여 주세요"가 뜬다 — 과거 표현·그래프에서 호칭 변화를 읽었지만 본문에 **넣지 않고 경고로만** 쓴 것. 프롬프트 v2(호칭 규칙 명시, 11/09)부터는 1차에 통과한다. v1 때는 호칭을 넣었다가 검증에 걸려 재생성했는데, 그 흔적이 이력에 "2회 시도"로 보이면 "검증이 과잉 모방을 막았다"는 설명 거리로 쓴다.
  - 비교로 조건 **B**를 한 번 더: 11/08 실측에서 B는 1차에 '서연 씨'를 넣었다가 검증에 걸려 재생성했다(이력의 "1회/2회 시도"로 보인다).
- 말할 것: 그래프는 "누가 누구와 어떤 관계였고 언제 바뀌었나"를 시간과 함께 기억한다. 설정값(격식 3)이 우선이고 그래프는 참고·경고.

## 3. 친구와 약속 — 흩어진 약속 잇기 (D vs C)
- 상대 **최유진**(친구). 과거 대화 10/16 "다음 달에 밥 한번 먹자"를 보여 준다.
- 첨삭: 상황 `일정 조율`, 조건 **C** → 원문 `다음 달 둘째 주 토요일 저녁 어때?` → 결과 "유진아 … 어때? 😊". 참고 표현은 뜨지만 밥 약속 메시지는 반만 걸린다.
- 조건 **D**로 다시 → **주의**에 "이전에 말한 밥 약속이라면 직접 덧붙여 주세요" — 그래프가 "11월에 밥 먹자고 제안했다" 사실을 연결했다. 평가 지표로는 recall 0.5 → 1.0.
- 말할 것: 원문에 없는 "밥"을 모델이 **지어 넣지 않는** 것이 설계 원칙. 사용자가 덧붙일지 결정한다.
